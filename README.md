# PDF Viewer Plus - Enhanced Fork

An enhanced fork of the original [vscode-pdfviewer](https://github.com/tomoki1207/vscode-pdfviewer) extension with extended functionality and additional features.

## About This Fork

This is an **enhanced community fork** that builds upon the excellent work of the original vscode-pdfviewer extension. While maintaining core PDF viewing capabilities, this fork adds powerful new features for PDF manipulation and enhanced user experience.

## Key Features

### Core Features (Original)
- Built-in PDF viewer with smooth rendering
- Navigation tools and zoom controls
- Custom scroll mode support
- Full-page navigation

### Enhanced Features (This Fork)
- ✨ **Delete PDF Pages** - Remove unwanted pages from your PDFs
  - Delete single pages with ease
  - Delete multiple pages by selection
  - Delete continuous page ranges
  - *Access via: Command Palette → search "Delete PDF Page"*
- 🎯 Improved UI/UX with custom icon
- 📦 Regular updates and maintenance

## Requirements

- Visual Studio Code 1.103.0 or higher

## Usage

1. Open any PDF file in VSCode
2. The PDF will be displayed in the built-in viewer
3. Use the toolbar for navigation and controls
4. To delete pages: Open Command Palette and search for "Delete PDF Page"

## Distinguishing Features

Compared to the original vscode-pdfviewer, this fork includes:
- Native PDF page deletion functionality
- Enhanced UI with custom branding
- Active maintenance and feature development
- Community-driven improvements
